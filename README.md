# 📊 Retail SQL Analysis

## 📌 Overview

This repository contains a collection of SQL exercises performed on a relational retail database.

The goal of this project is to strengthen SQL skills by working with realistic business-like data, focusing on data extraction, aggregation, and relational analysis across multiple tables.
---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Identify top customers and products
- Evaluate store and staff performance
- Understand customer purchasing behavior
- Analyze inventory and stock levels
- Calculate key business KPIs such as revenue and average order value

---

## 🗂️ Database Structure

The dataset includes the following main tables:

- `customers` – customer information
- `orders` – order details
- `order_items` – products within each order
- `products` – product catalog
- `categories` – product categories
- `brands` – product brands
- `stores` – store information
- `staffs` – employees managing orders
- `stocks` – inventory levels

---

## 🛠️ Tools Used

- SQL (SQLite syntax)
- JOIN operations
- Aggregations (SUM, AVG, COUNT)
- GROUP BY & HAVING
- Common Table Expressions (CTEs)

### 🔹 Inventory Analysis

- Monthly revenue trends
