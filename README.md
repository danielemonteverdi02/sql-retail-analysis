# 📊 Retail SQL Analysis Project

## 📌 Project Overview

This project is a SQL-based analysis of a retail database.  
The goal is to explore sales performance, customer behavior, product trends, and store efficiency using relational data.

The analysis is performed using standard SQL techniques such as **JOINs, aggregations, GROUP BY, subqueries, and Common Table Expressions (CTEs)**.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall sales performance
- Identify top customers and products
- Evaluate store and staff performance
- Understand customer purchasing behavior
- Analyze inventory and stock levels
- Calculate key business KPIs such as revenue and average order value

---

## 🗂️ Database Structure

The dataset includes the following main tables:

- `customers` – customer information
- `orders` – order details
- `order_items` – products within each order
- `products` – product catalog
- `categories` – product categories
- `brands` – product brands
- `stores` – store information
- `staffs` – employees managing orders
- `stocks` – inventory levels

---

## 🛠️ Tools Used

- SQL (SQLite syntax)
- JOIN operations
- Aggregations (SUM, AVG, COUNT)
- GROUP BY & HAVING
- Common Table Expressions (CTEs)

---

## 📊 Key Analyses Performed

### 🔹 Sales Analysis
- Total revenue per order
- Revenue by store
- Revenue by category and brand
- Top selling products

### 🔹 Customer Analysis
- Top customers by total spending
- Number of orders per customer
- Inactive customers (no orders)
- Average order value (AOV)

### 🔹 Store & Staff Performance
- Revenue per store
- Number of orders per store
- Best performing staff member
- Customer distribution per store

### 🔹 Product Analysis
- Best-selling products by quantity
- Most profitable products
- Products never sold
- Discount analysis

### 🔹 Inventory Analysis
- Stock levels per product
- Low stock products
- Stock vs sales comparison

### 🔹 Time-based Analysis
- Monthly revenue trends
- Daily revenue performance
- Order distribution over time
- Average shipping time
